## 🎯 Available Scenarios & Expected Results

Below is the complete catalog of scenarios available in the framework. You can run any scenario using:
`python run_agents.py <SCENARIO_NAME>`

---

### 1. `HELLO_AGENTS` (Sanity & Setup Test)
* **Command:** `python run_agents.py HELLO_AGENTS`
* **Description:** Initiates a simple multi-agent conversation where `task_coordinator_agent` asks `text_analyst_agent` for a cybersecurity joke.
* **Prerequisites:** Local Ollama or OpenAI API key.
* **Expected Result:**
  * Clean agent dialogue initiating a chat.
  * A cybersecurity joke generated by the LLM.
  * Successful termination message (`TERMINATE`).

---

### 2. `SUMMARIZE_RECENT_CISA_VULNS` (Threat Intelligence Digest)
* **Command:** `python run_agents.py SUMMARIZE_RECENT_CISA_VULNS`
* **Description:** 
  1. `cmd_exec_agent` downloads the official CISA Known Exploited Vulnerabilities feed (`known_exploited_vulnerabilities.json`) and extracts the latest 10 vulnerabilities via shell/`jq`.
  2. `text_analyst_agent` parses the JSON data into a structured summary.
* **Prerequisites:** Internet access, `curl`, `jq`.
* **Expected Result:** A formatted Markdown table listing:
  * Vendor / Product Name
  * Short vulnerability description & CVE ID
  * Reference links for remediation

---

### 3. `TTP_REPORT_TO_TECHNIQUES` (Threat Report Analysis)
* **Command:** `python run_agents.py TTP_REPORT_TO_TECHNIQUES`
* **Description:** `internet_agent` fetches a live Microsoft Security Threat Intelligence blog post analyzing custom post-compromise tools (e.g., Forest Blizzard CVE-2022-38028) and extracts all referenced MITRE ATT&CK TTPs.
* **Prerequisites:** Internet access.
* **Expected Result:** A comprehensive bulleted list of extracted MITRE ATT&CK technique IDs (e.g., `T1003 - OS Credential Dumping`, `T1059 - Command and Scripting Interpreter`) with context descriptions.

---

### 4. `TTP_REPORT_TO_ADVERSARY_PROFILE` (Automated Purple Teaming)
* **Command:** `python run_agents.py TTP_REPORT_TO_ADVERSARY_PROFILE`
* **Description:** 
  1. `internet_agent` downloads a DFIR ransomware threat report and extracts MITRE techniques.
  2. `caldera_agent` queries the MITRE Caldera server to find matching abilities for each technique.
  3. Automatically creates a brand-new **Adversary Profile** inside Caldera with the mapped attack abilities.
* **Prerequisites:** Active MITRE Caldera server running at `http://127.0.0.1:8888`.
* **Expected Result:** A new adversary profile registered inside MITRE Caldera populated with ready-to-execute attack abilities.

---

### 5. `DETECT_EDR` (Endpoint Detection & Response Identification)
* **Command:** `python run_agents.py DETECT_EDR`
* **Description:** 
  1. `internet_agent` downloads telemetry signature data from the open-source EDR-Telemetry project.
  2. `caldera_agent` queries the active Caldera agent to enumerate running Windows services.
  3. `text_analyst_agent` correlates running services against telemetry signatures to identify installed EDR products.
* **Prerequisites:** Active MITRE Caldera server with an active endpoint agent connected.
* **Expected Result:** An audit report identifying active endpoint security products (e.g., CrowdStrike, Defender, SentinelOne, Elastic).

---

### 6. `DETECT_AGENT_PRIVILEGES` (Endpoint Privilege Audit)
* **Command:** `python run_agents.py DETECT_AGENT_PRIVILEGES`
* **Description:** `caldera_agent` executes PowerShell privilege check commands on the remote target host, and `text_analyst_agent` evaluates whether the agent has Standard User, Administrator, or SYSTEM rights.
* **Prerequisites:** Active MITRE Caldera server with connected agent.
* **Expected Result:** Structured privilege table and a clear determination of privilege level.

---

### 7. `IDENTIFY_EDR_BYPASS_TECHNIQUES` (EDR Telemetry Gap Analysis)
* **Command:** `python run_agents.py IDENTIFY_EDR_BYPASS_TECHNIQUES`
* **Description:** `internet_agent` analyzes public EDR telemetry matrices to identify detection gaps and unmonitored telemetry categories for Elastic EDR.
* **Prerequisites:** Internet access.
* **Expected Result:** A list of telemetry sub-categories and security blind spots to assist detection engineers.

---

### 8. `HELLO_CALDERA` (Remote GUI Action)
* **Command:** `python run_agents.py HELLO_CALDERA`
* **Description:** `caldera_agent` sends a PowerShell command through Caldera to pop up an interactive desktop GUI message box with a cybersecurity joke on the remote agent machine.
* **Prerequisites:** Active Caldera server with a Windows agent running in an interactive user session.
* **Expected Result:** A physical pop-up dialog box displayed on the target endpoint screen.

---

### 9. `COLLECT_CALDERA_INFO` (Caldera Environment Discovery)
* **Command:** `python run_agents.py COLLECT_CALDERA_INFO`
* **Description:** Queries Caldera's REST API `/api/v2/agents` and `/api/v2/operations` to list active agent PAWs and operation identifiers.
* **Prerequisites:** Active Caldera server.
* **Expected Result:** API response output displaying active agent identifiers and operation states.
